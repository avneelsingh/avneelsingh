## 🚀 Featured Projects

### 1. PrepPro — Full-Stack Learning Platform
**Tech Stack:** HTML, CSS, JavaScript, Firebase, Cloud Firestore

A learning platform designed to make preparation more engaging through interactive study tools and progress tracking.

- Google authentication and personalized learning experience.
- Interactive flashcards and practice features.
- XP-based gamification and learning analytics.
- Firebase integration for authentication and cloud data storage.

🔗 **Live Demo:** [prepyproo.web.app](https://prepyproo.web.app/)

### 2. Medical Insurance Premium Prediction
**Tech Stack:** Python, Pandas, NumPy, Scikit-learn, XGBoost, Jupyter Notebook

A machine learning project for predicting medical insurance premiums using demographic and other relevant features.

- Performed data preprocessing and feature engineering.
- Experimented with Linear Regression, Random Forest, and XGBoost.
- Explored stacking-based ensemble learning.
- Evaluated model performance and developed an interactive prediction workflow using ipywidgets.

### 3. CNN-Based Reuse and Recycling Recommendation System
**Tech Stack:** Python, Deep Learning, Convolutional Neural Networks (CNN), Blockchain

An intelligent system exploring image-based classification to support reuse and recycling decisions.

- Applied CNN-based image classification techniques.
- Explored recommendations for reuse and recycling.
- Incorporated blockchain concepts to support traceability and transparency.

### 4. Awesome Tic-Tac-Toe Verse
**Tech Stack:** HTML, CSS, JavaScript

An interactive Tic-Tac-Toe game with features designed to improve gameplay and user experience.

- Single-player mode with AI and multiple difficulty levels.
- Two-player mode with score tracking and customizable player names.
- Sound effects, animations, and responsive design.
- Light and dark themes.

🔗 **Live Demo:** [awesome-tic-tac-toe-verse.netlify.app](https://awesome-tic-tac-toe-verse.netlify.app/)

### 5. Student Registration Management System
**Tech Stack:** Python, Tkinter, SQLite

A desktop application for managing student-related records through a graphical interface.

- Built the user interface using Tkinter.
- Used SQLite for persistent data storage.
- Implemented database-backed registration and record management workflows.
